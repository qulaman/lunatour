# Luna Tour — лендинг «Китай за 10 дней»

Одностраничный сайт тура 24.10–02.11.2026. Открывается двойным кликом по `index.html`,
для публикации достаточно загрузить папку целиком на любой хостинг (Netlify, GitHub Pages, обычный FTP).

## Структура

| Файл / папка | Что это |
|---|---|
| `index.html` | Разметка страницы: шапка, hero, карта, цена, контакты |
| `css/style.css` | Все стили, адаптив, анимации |
| `js/tour-data.js` | **Тексты тура (русский)**: города, даты, достопримечательности, программа по дням, что входит в цену |
| `js/tour-data.kk.js` | То же на казахском, структура один в один |
| `js/i18n.js` | Переключатель RU / KZ и словарь казахских переводов для статичных текстов страницы |
| `js/main.js` | Логика: отрисовка карты и маршрута, автопоказ, карточки городов, анимации |
| `js/map-data.js` | Контуры провинций Китая и координаты городов (генерируется, руками не править) |
| `Images/logo.png` | Логотип на прозрачном фоне |
| `Images/photos/` | Фото достопримечательностей (1400–2200 px) и папка `thumbs/` с уменьшенными копиями |
| `Images/photos/CREDITS.txt` | Источники и лицензии фотографий (Wikimedia Commons) |
| `Images/banks/` | Логотипы Kaspi.kz и Halyk Bank (SVG) |

## Как менять контент

- **Тексты, даты, список достопримечательностей** — только в `js/tour-data.js`. Карта, карточки и блок «Города» строятся из этого файла автоматически.
- **Списки «В стоимость входит» и «Оплачивается отдельно»** — массивы `included` и `notIncluded` в `js/tour-data.js`, каждый пункт `{ icon, text }`. Доступные иконки: `plane`, `train`, `transfer`, `hotel`, `guide`, `food`, `taxi`, `ticket`.
- **Цена, рассрочка, телефон, WhatsApp, Instagram** — в `index.html` (поиск по `850 000`, `77053803402`, `luna_tour.kz`).
- **Видео из Instagram** — в секции `<section class="video">` блок `<blockquote class="instagram-media">` с адресом публикации в `data-instgrm-permalink`. Официальный скрипт Instagram (`embed.js`) сам подгоняет высоту карточки. Чтобы заменить ролик, подставьте адрес другой публикации в `data-instgrm-permalink` и в ссылку внутри блока.
- **Советы «Полезно знать»** — статичный HTML в `index.html` (секция `<section class="tips">`), температуры по городам и чек-лист правятся там же.
- **Обратный отсчёт до вылета** в блоке контактов считает дни, часы и минуты до 24.10.2026 (дата задана в `js/main.js`, поиск по `2026-10-24`). После вылета блок сам скрывает цифры.
- **Достопримечательности** открываются по клику в модальном окне с большим фото и описанием; стрелки листают места одного города, Esc закрывает.
- **Карта** проигрывает маршрут автоматически, когда попадает в экран. Клик по городу или кнопке 01–05 переводит к остановке, кнопка в углу карты ставит показ на паузу.
- **Заменить фото** — положите новый JPEG с тем же именем в `Images/photos/` и уменьшенную копию (до 720 px) в `Images/photos/thumbs/`.
- **Добавить достопримечательность** — добавьте объект `{ name, desc, img }` в массив `attractions` нужного города и файл `img.jpg` в обе папки с фото.

## Казахская версия

- Переключатель RU / KZ в шапке. Выбор запоминается в браузере и в адресе (`?lang=kk`), при смене языка страница перезагружается.
- Русский текст — исходный: он лежит в `index.html` и `js/tour-data.js`. Казахский берётся из `js/tour-data.kk.js` (данные тура) и словаря в `js/i18n.js` (все остальные надписи).
- Словарь в `i18n.js` устроен как пары «русская фраза → казахская». Если вы меняете русский текст в `index.html`, поменяйте и ключ в словаре, иначе фраза останется на русском в казахской версии.
- Ссылку на казахскую версию можно давать напрямую: `index.html?lang=kk`.

## Внешние зависимости

Шрифты Google Fonts (Montserrat, Onest, Playfair Display, Noto Serif SC — все с поддержкой казахских букв) и библиотека GSAP подгружаются с CDN. Встраивания Instagram тоже требуют интернета. Без сети страница работает, но с системными шрифтами и без анимации карты (карта показывается целиком, города переключаются кнопками).
